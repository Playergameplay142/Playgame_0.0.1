
Playgame, Python ile geliştirilmiş 49 farklı mini oyunu ve uygulamayı tek bir modern masaüstü arayüzünde toplayan eğlenceli bir koleksiyondur.

🚀 Özellikler
Tek bir ana menü (launcher.exe) üzerinden 49 farklı oyuna hızlı erişim.

Python ve gerekli kütüphanelerle bağımsız olarak çalışabilen, harici kurulum gerektirmeyen pratik yapı.

Kolay kullanım sağlayan şık masaüstü arayüzü.

📦 Kurulum
Projenin Releases sayfasından güncel playgame_0.0.1_setup.exe dosyasını indirin.

Kurulum sihirbazını çalıştırarak oyunu bilgisayarınıza kurun.

Masaüstünde oluşan kısayol ile ana menüyü açın ve dilediğiniz oyunu oynamaya başlayın!

🛠️ Kullanılan Teknolojiler
Python

Tkinter (Arayüz ve Menü)

PyInstaller (Uygulama Paketleme)

Inno Setup (Kurulum Sihirbazı)
